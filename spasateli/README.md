# «Спасатели, или Убить фюрера» — тестовая ИИ-экранизация

Личный некоммерческий эксперимент. Публикация и монетизация возможны только с письменного разрешения правообладателя (автор — Олег Курылёв, издатель — «Альпина.Проза»).

## Файлы

| Файл | Назначение |
|---|---|
| `shots.json` | суффикс стиля и 9 кадров сцены (`image`, `motion`, `audio`, длительность) |
| `film.py` | пайплайн: ключевые кадры → image-to-video → скачивание → склейка |
| `jobs.json` | создаётся автоматически: job ID, статус, стоимость каждой попытки |

## Источник

- **Книга:** Олег Курылёв, «Спасатели, или Убить фюрера», «Альпина.Проза», 2026, 572 с. (первое издание — «Убить фюрера», Эксмо, 2007).
- **Сюжет:** историки Савва Каратаев и Вадим Нижегородский отправлены машиной времени в Европу 1911 года, не возвращаются и зарабатывают на знании будущего.
- **Легальный фрагмент (с. 1–30):** https://alpina-proza.ru/media/fragments/Spasateli_1-30.pdf

## Тест на $10 — сцена в казино «Фортуна» (с. 18–24)

Берлин, 15 декабря 1911 года. Из газетной заметки Савва знает: русский купец Овчинников поставит на «17 чёрное», а выпадет «18 красное». Савва ставит всё на 18. Заметка умолчала, что купец ставил на 17 дважды: Савва играет на первой попытке и теряет всё, а 18 выпадает на второй.

Стиль: рисованная анимация под автохромы 1910-х. Раскадровка — 9 кадров, 41 с экранного времени (см. `shots.json`).

## Запуск

```bash
pip install httpx          # ffmpeg нужен для шага concat
export OPENROUTER_API_KEY=...

python film.py keyframes --variants 2   # keyframes/shot_NN_vK.png, ~$0.8
# вручную: лучший вариант каждого кадра скопировать в keyframes/shot_NN.png

python film.py submit --shots 1 --takes 1   # пробный прогон одного кадра (~$0.14)
python film.py poll
python film.py submit --takes 5             # вся сцена; для уже снятых кадров укажите --shots
python film.py poll                         # clips/shot_NN_a.mp4 … _e.mp4
python film.py cost
python film.py concat --pick 1:b,3:d,6:a    # не указанные кадры берутся из дубля a
```

Переменные окружения: `VIDEO_MODEL` (по умолчанию `bytedance/seedance-2.0-mini`), `VIDEO_RESOLUTION` (`480p`), `IMAGE_MODEL` (`bytedance-seed/seedream-5-0-pro`), `KEYFRAME_BASE_URL`.

**Важно:**
- `submit` записывает job ID в `jobs.json` сразу после ответа сервера. `poll` можно прерывать и запускать снова — повторной оплаты не будет. Повторный `submit` без `--shots` отправит задания заново и спишет деньги.
- Документация OpenRouter требует для `frame_images` прямой публичный HTTPS-URL. Без `KEYFRAME_BASE_URL` скрипт шлёт кадры как data URL; если провайдер их отклонит, выложите `keyframes/` на любой публичный хостинг и задайте `KEYFRAME_BASE_URL`.
- Ошибка модерации придёт как HTTP-ошибка при `submit` или статус `failed` при `poll` — текст сохраняется в `jobs.json`.

## Что проверить по итогам теста

- Держится ли внешность Саввы и Овчинникова между кадрами. Если нет — следующий шаг: листы персонажей и передача их в `input_references` (Seedream принимает до 14 референсов).
- Процент брака на кадр и реальная стоимость секунды (`python film.py cost`).
- Качество встроенного звука, нужна ли отдельная озвучка (ElevenLabs).
